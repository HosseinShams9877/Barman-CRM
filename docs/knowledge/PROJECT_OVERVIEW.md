> خروجی Phase 0 — بازرس‌نگاری کامل نسخه نمایشی موجود، بدون هیچ‌گونه پیاده‌سازی.
> همه ارقام و نام فایل‌ها مستقیماً از کد منبع Demo استخراج شده‌اند.

## ۱. هویت محصول

سامانه یکپارچه **فروش، تولید و انبار** یک کارگاه کوچک تولید محصولات سه‌بعدی (نما، پنل، تابلو) است که دو خط محصول دارد:

- **محصولات تولیدی (`line: "prod"`)**: با مواد اولیه (کیلو/لیتر) در کارگاه تولید می‌شوند و به انبار دپو می‌روند.
- **محصولات نمایندگی (`line: "agency"`)**: کالای آماده‌ای است که از تأمین‌کننده خریداری می‌شود.

واحد فروش محصولات تولیدی **متر مربع (م²)** و محصولات نمایندگی **عددی** است. مواد اولیه کیلویی/لیتری خریداری می‌شوند.

نام برند در کد و رابط: **بارمان / BARMAN 3D WORKS** (`login.html`، `S.company`).

## ۳. جمع‌بندی دامنه کسب‌کار

جریان اصلی ارزش (مشتری‌محور):

۱. **سرنخ** (Lead) وارد می‌شود (منبع ورود، کارشناس فروش، مرحله خام/فرصت) →
۲. **پیش‌فاکتور** (PF) صادر می‌شود و سرنخ به مرحله `pf` می‌رود →
۳. **تأیید مشتری و پرداخت** (نقد/چک/نسیه) →
۴. **تأمین**: محصول تولیدی با کسر مواد اولیه **تولید** می‌شود، یا کالای نمایندگی **خرید** می‌شود →
۵. **ورود به انبار دپو**، آماده‌سازی و **تحویل** به مشتری؛ سرنخ به `won`.

جریان پشتیبان: **خرید** مواد/کالای نمایندگی (درخواست از تولید → تأیید مدیر → پرداخت مالی → رسید انبار) و **مالی** (دریافتنی‌ها، پرداختنی‌ها، چک‌های صیادی، ثبت هزینه).

## ۴. فهرست نقش‌ها (۷ نقش، ۸ کاربر نمونه)

`management` (مدیر)، `admin` (ادمین)، `finance` (مالی)، `salesManager` (مدیر فروش)، `sales` (کارشناس فروش)، `production` (مدیر تولید)، `depot` (انبار دپو) — تعریف `ROLES` در `core.js`؛ کاربران نمونه `USERS0` شامل `u1`…`u8`.

(جزئیات کامل در `USER_ROLES_AND_PERMISSIONS.md`.)

## ۵. محدودیت‌های اساسی نسخه فعلی (که معماری هدف باید برطرف کند)

- **تمام اعتبار سنجی سطح دسترسی در کلاینت است**؛ سرور فقط احراز هویت و فهرست سفید collectionها را اجرا می‌کند ( مستندسازی در `AUTH_AND_PERMISSION_ARCHITECTURE.md`).
- منطق کلیدی (مجموع پیش‌فاکتور، کسر مواد، رزرو موجودی) در رشته‌های HTML درون JS نهفته است و آزمایش خودکار ندارد.
- ۶۷٪ کلاس‌های CSS بدون ارجاع هستند (۱٬۰۲۴ از ۱٬۵۱۷ توکن کلاس) و ۵۳٪ خطوط CSS در انتخابگرهای کاملاً مرده قرار دارند.
- همگام‌سازی مبتنی بر snapshot کامل + نظرسنجی، بدون راهکار تعارض.

## ۶. اهداف فاز بعدی (طبق سند راهبری)

برنامه هدف: Next.js App Router + React + TypeScript سخت‌گیرانه + Tailwind + Prisma 6 (PostgreSQL در تولید، SQLite در توسعه) + TanStack React Query v5 + Zod + Vitest، با توکن‌های متمرکز CSS و معماری ماژولار `src/modules/<module>/…` — **بدون تغییر قوانین کسب‌کار**.
