# UI_UX_DESIGN_SYSTEM — سیستم طراحی رابط کاربری Demo

> منبع: `app/br.css` (۳٬۸۶۴ خط)، بررسی بصری و رفتار صفحات. این سند ویژگی‌های واقعی را ثبت می‌کند تا در معماری هدف بازسازی شود.

## ۱. اصول پایه

- **زبان و جهت**: فارسی، RTL (`<html lang="fa" dir="rtl">`)؛ ارقام فارسی در رابط.
- **فونت**: Vazirmatn (Regular + Bold، woff2)؛ `--font:"Vazirmatn",Tahoma,sans-serif`.
- **تایپوگرافی پایه**: `font-size:14px`، `line-height:1.75` (متن چندخطی).
- **متن دوزبانه**: کلاس `.ltr { direction:ltr; unicode-bidi:isolate }` برای کدها/شماره‌ها.
- **آیکون‌ها**: `.icon` ۲۲px، stroke 1.8 (فهرست آیکون‌ها در تابع `icon()` در core.js).
- **تمرکز**: `:focus-visible { outline:3px solid rgba(22,98,216,.45) }`.

## ۲. چیدمان

- **ساید‌بار**: عرض ثابت `--side:256px` (در نقاط شکست جمع می‌شود).
- **کارت‌ها**: پس‌زمینه `--card`، گوشه `--radius:14px` (کارت‌ها) و `--radius-sm:10px` (موارد کوچک).
- **سایه**: `--shadow:0 1px 2px rgba(15,35,80,.05),0 6px 20px rgba(15,35,80,.05)`.
- **خطوط جدول**:`--line` روی `--line-2`.

## ۴. الگوهای مشاهده‌شده

- **shell**: `X.shell({...})` در `core.js` اسکلت هر صفحه (ساید‌بار + محتوای اصلی + شناور) را می‌سازد.
- **Cards**: `.pv-c` (کارت سفارش در تولید)، `.pv-j` (کارت کار)، `.ld-tile` (کاشی داشبورد)، `.fl-list`.
- **جدول‌ها**: `.tbl` با stripes.
- **chipها**: معروف‌ترین: chip «کمتر از حداقل» قرمز، chip «ناقص» چک صیادی، chip های وضعیت هرزمان.
- **نوارهای پیشرفت**: `.pv-tl` (progress bar با حالت late)، `.pv-bar` (ستونی)، `.pv-hi` (نوار سلامت مواد).
- **دیالوگ‌ها**: `<dialog>` بومی خیلی استفاده شده (sync guard هنگام باز بودن)؛ کلاس `.dlg-wide` برای دیالوگ‌های پهن (مثلاً پروفایل مشتری).
- **فرم**: `X.readDate` datepicker خورشیدی، ورودی‌های پولی با تبدیل ارقام و تفکیک‌کننده `٬`/`,`.
- **حالت حداقل (minimal-mode)**: در محیط صفحه‌بندی کشیده (دومین `:root` در `br.css` خط ۲۳۸۹ + بخش ۳۵۵۳–۳۵۸۴) رنگ‌های پس‌زمینه تیره‌تر و خطوط/sایه‌ها بازنویسی می‌شوند.

## ۶. واکنش‌گرایی (وضع موجود)
