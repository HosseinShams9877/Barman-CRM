# GLOSSARY — واژه‌نامه دامنه بارمان

> اصطلاحات کسب‌کار و فنی که در مستندات استفاده می‌شوند. منبع: کد Demo و فهرست‌های آن.

## ۱. اصطلاحات کسب‌کار

| اصطلاح | معنی |
|---|---|
| **پیش‌فاکتور (PF)** | سند سفارش/پیش‌فاکتور با شناسه `PF-xxxx` |
| **سرنخ (Lead)** | رکورد بازاریابی با شناسه `LD-xxxx` |
| **حساب (Account)** | شخص/شرکت مشتری یا طرف قرارداد با شناسه `AC-xxx` |
| **خط محصول** | `prod` (تولیدی، فروخته به م²) یا `agency` (نمایندگی، فروخته به عدد) |
| **دپو** | انبار محصول آماده (`wh: "depot"`) |
| **انبار مواد** | انبار مواد اولیه (`wh: "raw"`) |
| **ماده اولیه (RM)** | مواد مصرفی تولید با شناسه `RM-1xx` |
| **BOM** | صورت‌مادی محصول: مواد تشکیل‌دهنده و مقدار مصرفی هر م² |
| **کار تولید (Job)** | دستور تولید یک محصول با شناسه `PJ-xxx` |
| **خرید (Buy)** | سند خرید مواد/کالای نمایندگی با شناسه `BY-xxx` |
| **حرکت (Move)** | رکورد ورودی/خروجی انبار |
| **رسید** | ورود کالا به انبار (وضعیت `recv` یا `kind: "job"/"buy"`) |
| **رزرو نقدی (resv)** | مبلغی که مشتری هنگام تأیید سفارش پرداختی است |
| **نسیه (credit)** | نوع پرداخت اعتباری (پرداخت در سررسید) |
| **چک صیادی (sayad)** | چک‌های ثبت‌شده در سامانه صیاد |
| **سررسید** | تاریخ سررسید چک/بدهی |
| **ضایعات (waste)** | مقدار محصول تولیدشده‌ی معیوب در QC |
| **موجودی آزاد** | موجودی انبار منهای رزرو شده |
| **موجودی در راه** | اقلام در حال انتقال به انبار (`pend`، `sent`) |
| **حداقل موجودی (min)** | آستانه هشدار خرید ماده |
| **کرایه حمل (ship)** | هزینه ارسال در سفارش |
| **هزینه نصب (install)** | هزینه نصب در سفارش |
| **مالیات (vat)** | درصد مالیات بر ارزش افزوده از تنظیمات |
| **انقضای پیش‌فاکتور** | تعداد روز اعتبار پیش‌فاکتور (`validDays`) |
| **سقف تخفیف (discountCap)** | حداکثر تخفیف مجاز هر نقش |
| **منبع ورود (source)** | کانال ورود سرنخ (از فهرست `sources`) |
| **مرحله سرنخ** | `raw` (خام) → `opp` (فرصت) → `pf` (پیش‌فاکتور) → `won`/`lost` |

## ۲. اصطلاحات فنی

| اصطلاح | معنی |
|---|---|
| **snapshot polling** | بارگذاری کامل داده هر ۳ ثانیه و مقایسه `rev` |
| **rev** | شماره نسخه داده در `kv` (Postgres) یا در حافظه (درایو فایل) |
| **sync guard** | جلوگیری از همگام‌سازی هنگام باز بودن `<dialog>` یا آلوده بودن پیش‌نویس |
| **OPS** | پرچم «بدون اطلاعات مالی» برای نقش‌های production/depot (`X.noMoney`) |
| **JDN** | روز ژولین (Julian Day Number) — نمایش داخلی تقویم |
| **JDF** | الگوریتم تبدیل میلادی ↔ خورشیدی جلالی |
| **Demo** | نسخه نمایشی موجود (پوشه `پلتفرم نهایی تیم بارمان`) |
| **سند (Doc)** | یک رکورد JSON در پایگاه داده سندی |
| **collection** | مجموعه‌ای از اسناد هم‌نوع (`orders`، `leads`، …) |
| **seq** | شمارنده هر مجموعه شناسه (`seq-PF.txt` یا جدول `seq`) |
| **فهرست سفید collectionها** | محدودیت سرور: فقط مجموعه‌های مجاز قابل دسترسی |
| **`X` / `B` / `L`** | فضاهای نام `window.BR` / `window.BRF` / `window.BRL` |

| `production` | مدیر تولید |
| `depot` | انبار دپو |

## ۴. مخفف‌های فنی پشته هدف

| اصطلاح | معنی |
|---|---|
| **App Router** | مسیریابی برنامه Next.js (پوشه `app/`) |
| **Route Handler** | توابع مسیر API در `src/app/api/` |
| **React Query** | TanStack React Query v5 — مدیریت وضعیت سرور |
| **Zod** | کتابخانه اعتبارسنجی اسکیمای داده |
| **Prisma** | ORM برای PostgreSQL/SQLite |
| **Vitest** | چارچوب آزمون واحد |
| **Tailwind** | چارچوب CSS ابزاری |
| **CSR/SSR** | رندر سمت کلاینت/سرور |
