# MASTER_ROADMAP — نقشه راه اصلی پیاده‌سازی

> فاز صفر (بررسی و طراحی) کامل است. این نقشه راه طبق سند راهرسی اجباری، قبل از شروع Phase 1 به تأیید کاربر نیاز دارد. **بدون تأیید صریح، Phase 1 شروع نمی‌شود.**

## ۱. مرور فازها

| فاز | نام | شرح کوتاه | مدت تخمینی |
|---|---|---|---|
| **۰** | مهندسی معکوس و طراحی | مستندسازی کامل Demo، معماری، نقشه راه (این مجموعه) | تکمیل‌شده |
| **۱** | پایه و ابزار | پروژه Next.js، TypeScript strict، توکن‌های CSS، Vitest، لایه core | ۱–۲ هفته |
| **۲** | پلتفرم اصلی | Prisma + PG/SQLite، احراز هویت سرور، مجوز RBAC، موتور تقویم، قالب‌بندی، اعتبارسنجی | ۲–۳ هفته |
| **۳** | CRM سرنخ‌ها و مشتریان | ماژول leads + customers (کانبان، تاریخچه پیگیری) | ۲–۳ هفته |
| **۴** | خط لوله فروش | ماژول sales (سفارش/PF، ۱۱ مرحله، پرداخت، چک، چاپ امن) | ۳–۴ هفته |
| **۵** | تولید و انبار | ماژول‌های production + inventory (کار تولید، حرکت‌ها، BOM، کف موجودی) | ۲–۳ هفته |
| **۶** | خرید و مالی | ماژول‌های purchasing + finance (وصول/پرداخت، چک صادره، تراکنش) | ۲–۳ هفته |
| **۷** | مدیریت و گزارش | admin (کاربران، تنظیمات، کاتالوگ، فهرست‌ها)، reports، داشبورد home | ۲ هفته |
| **۸** | سخت‌افزاری واکنش‌گرا، آزمون و مهاجرت | تکمیل breakpoint‌ها، پوشش آزمون، مهاجرت داده از Demo، آماده‌سازی launch | ۲–۳ هفته |

## ۲. ترتیب و وابستگی

See `PHASE_DEPENDENCIES.md` برای نمودار کامل. خط سیر:

```
۱ (پایه) → ۲ (پلتفرم) → ۳ (CRM) ─┬→ ۴ (فروش) → ۵ (تولید/انبار) ─┬→ ۶ (خرید/مالی) → ۷ (مدیریت/گزارش) → ۸ (سخت‌سازی)
                                   └→ (customers در ۳)             └→ (purchasing وابسته به ۵)
```

## ۳. اصول راهبری (اعمال‌شده در همه فازها)

۱. **فارسی‌اول و RTL‌اول** — هر فاز با محتوای فارسی واقعی آزمایش می‌شود.
۲. **بدون تغییر قوانین کسب‌کار** — همه قوانین Demo حفظ می‌شوند (سوالات باز در `OPEN_QUESTIONS.md` فقط با پاسخ کاربر حل می‌شوند).
۳. **مجوز سرور** — از Phase ۲ به بعد، هیچ مسیری بدون `requirePermission`.
۴. **آزمون همگام** — هر فاز آزمون‌های خود را همراه با پیاده‌سازی تحویل می‌دهد (نه در انتها).
۵. **Demo دست‌نخورده** — تا انتها Phase ۸ منبع داده.
۶. **واکنش‌گرا** — هر کامپوننت در ۵ breakpoint از همان ابتدا.
